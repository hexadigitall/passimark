1. EXECUTIVE SUMMARY & COMPETITIVE POSITIONING
--------------------------------------------------------------------------------
Passimark is designed to supersede legacy certification simulators like Visual 
CertExam Suite (VCE). While VCE relies on static, file-based exam execution, 
Passimark introduces real-time Computerized Adaptive Testing (CAT) using Item 
Response Theory (IRT). 

To achieve decisive market dominance over VCE, Passimark is expanding beyond adaptive 
testing to support rich interactive question types, non-linear exam review, 
visual GUI authoring, and a portable file packaging format (.pmkx) paired with an 
offline player engine.
